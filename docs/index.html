为「把事情做完」而设计

原版代码重打包 + 十处最小侵入补丁，界面功能与官方版完全一致

二十箱子 GTD 体系

收件箱 → 今日 / 下一步 / 明日 / 日程 / 将来也许 / 等待，配合项目、目标、情境、过滤器。箱子规则严格还原原版语义：今日含逾期、日程含全部重复任务。

重复任务引擎

每天 / 每 N 天 / 每周多选 / 每月按日期 / 每月第几周周几 / 每年。完成时自动生成下一实例，按原始锚点推进日期，跨月自动跳过不存在的日期。

SmartAdd 快速添加

通知栏常驻入口，一句话创建任务：「明天 9:00-11:00 交报告 #工作 !高」——自然语言日期、时间段、标签、优先级全部自动解析。

每日计划与回顾

早晨 8 点计划今天要做什么，晚上 8 点回顾完成了什么。逾期任务一键推迟到明天，完成数据本地统计。

提醒不遗漏

每任务多时刻提醒，闹钟级精确触发，通知栏可直接「完成」或「稍后提醒」。重启手机自动恢复全部提醒。

GitHub 云备份

本地版专属：设置页一键把整个任务库（gzip 压缩）备份到你的私有 GitHub 仓库，换机恢复、历史可回滚。Token 仅存本机，数据不经过任何第三方。

本地优先 · 绝对隐私

数据 100% 存储在手机本地 SQLite，不联网、不注册、不上传。搜索、拖拽排序、垃圾桶、PIN 保护一应俱全。
